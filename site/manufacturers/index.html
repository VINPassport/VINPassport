Security and data

What lives where

The answers procurement and IT security ask for first.

On the ledgerA sealed fingerprint of each value, never the value and never the key that seals it.
Vehicle identifiersRecords are found by a fingerprint of the identifier, derived under a network key; the identifier itself is never written to the ledger.
Who can writeA named set of registrars. Adding or removing one takes two registrars' approval, and every change is announced on the ledger.
Integrity rulesFixed per field at creation. Forward-only fields refuse a lower value inside the proof.
ProofsTransactions are built, proven and signed by the registrar.
FeesChecking a passport is free for everyone. Network fees for issuing and updating are agreed with each manufacturer.
Source codeOpen source under Apache-2.0. Read the contract
Data protectionWhat you send us through this site, and why, is in the privacy notice. Passport data has its own statement, written with counsel before any real vehicle is recorded.
StatusRunning on Midnight's Preview test network since 9 November 2026: deployed, exercised end to end and read back from the public indexer. 176 contract tests. Mainnet launch coming.
